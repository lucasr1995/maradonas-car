⚠️ Importante: O arquivo firebase-config.js precisa ser configurado antes de hospedar. Siga os passos abaixo.

1 Criar Conta no Firebase Gratuito

  1. Acesse console.firebase.google.com
  2. Faça login com sua conta Google (Gmail)
  3. Clique em "Criar um projeto"
  4. Digite o nome: maradonas-car
  5. Desative o Google Analytics (não é necessário) → clique "Criar projeto"
  6. Aguarde a criação (cerca de 30 segundos)
✅ O plano Spark (Gratuito) do Firebase inclui: 1GB de banco de dados, 5GB de armazenamento de fotos, 10GB de transferência/mês. Mais que suficiente para uma revenda de carros!

2 Ativar o Firestore (Banco de Dados)

  1. No painel do seu projeto, clique em "Firestore Database" no menu lateral
  2. Clique em "Criar banco de dados"
  3. Selecione "Iniciar no modo de produção"
  4. Escolha o local: "southamerica-east1" (São Paulo – mais rápido para o Brasil)
  5. Clique em "Concluído"

Agora configure as regras de segurança. Clique na aba "Regras" e cole o código abaixo:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Qualquer pessoa pode LER os carros (visitantes do site)
    match /carros/{carroId} {
      allow read: if true;
      allow write: if false; // apenas via Admin SDK (seguro)
    }
  }
}

Clique em "Publicar".

⚠️ Nota: Com esta configuração, visitantes só podem ver os carros, nunca alterar. O admin usa autenticação separada pelo painel.

3 Ativar o Storage (Armazenamento de Fotos)

  1. No menu lateral, clique em "Storage"
  2. Clique em "Começar"
  3. Aceite as regras padrão → clique "Avançar"
  4. Escolha o local: "southamerica-east1" → "Concluído"

4 Obter as Credenciais do Firebase

  1. Clique no ícone de engrenagem ⚙️ → "Configurações do projeto"
  2. Role até a seção "Seus aplicativos"
  3. Clique no ícone </> (Web)
  4. Digite o nome do app: maradonas-car-web
  5. NÃO marque "Firebase Hosting" por enquanto
  6. Clique em "Registrar app"
  7. Você verá um bloco de código assim:
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "maradonas-car.firebaseapp.com",
  projectId: "maradonas-car",
  storageBucket: "maradonas-car.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};
🔑 Copie esses valores! Você vai precisar deles no próximo passo.

5 Configurar o Arquivo firebase-config.js

Abra o arquivo firebase-config.js com o Bloco de Notas (clique direito → Abrir com → Bloco de notas).

Substitua os valores de exemplo pelos valores reais que você copiou:

const FIREBASE_CONFIG = {
  apiKey: "COLE_AQUI_SUA_apiKey",
  authDomain: "COLE_AQUI_SEU_authDomain",
  projectId: "COLE_AQUI_SEU_projectId",
  storageBucket: "COLE_AQUI_SEU_storageBucket",
  messagingSenderId: "COLE_AQUI_SEU_messagingSenderId",
  appId: "COLE_AQUI_SEU_appId"
};

// Número de WhatsApp (com código do país, sem espaços ou símbolos)
const WHATSAPP_NUMBER = "5531999995555"; // ← Altere para o número real!

const STORE_NAME = "Maradona's Car";

Salve o arquivo.

6 Hospedar no Vercel Gratuito

  1. Acesse vercel.com e crie uma conta gratuita
  2. Clique em "Add New Project"
  3. Selecione "Browse" e escolha a pasta descompactada do site (não o .zip)
  4. Clique em "Deploy"
  5. Aguarde 1-2 minutos → seu site estará no ar!
✅ O Vercel gera um link automático tipo maradonas-car.vercel.app. Você pode usar esse link ou conectar um domínio próprio.

7 Conectar Domínio Próprio (Opcional)

Para usar www.maradonascar.com.br:

  1. Registre o domínio em registro.br (~R$ 40/ano)
  2. No Vercel, vá em Settings → Domains
  3. Digite seu domínio e siga as instruções para apontar o DNS
  4. Em 24h o site estará no seu domínio

❓ Dúvidas Frequentes

O Firebase é realmente gratuito?
Sim! O plano Spark cobre: 50.000 leituras/dia, 20.000 escritas/dia, 5GB de fotos. Para uma revenda de carros com algumas centenas de veículos, isso é mais do que suficiente.
E se eu precisar de mais capacidade?
O plano pago do Firebase (Blaze) custa apenas pelo que usar, com preços muito baixos. Uma revenda típica gastaria menos de R$ 10/mês mesmo no plano pago.
Como faço backup dos dados?
No Firebase Console → Firestore → clique nos 3 pontos → "Exportar dados". Isso baixa todos os seus veículos.
Posso usar no celular para cadastrar carros?
Sim! O painel admin funciona em celular. Acesse seusite.vercel.app/admin.html pelo navegador do celular.
